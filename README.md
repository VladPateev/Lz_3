# Лабораторная работа 3: Обучение угадывания картинок животных

## Лучшей моделью оказалось обучение на входных:
    - BATCH_SIZE = 64        
    - EPOCHS = 8
    - LEARNING_RATE = 0.001 
Размер картинки был ужат до 144 * 96 * 3
## Самой лучшей версией обучения стало 80,6% (best_model_80.pth)
Обучалась на карте Nvidia 5060, 16 ГБ. Но так же на процессре intel core ultra 5 16 Гб
## Как проверять и что запускать

Обучение ИИшки:
```bash
python train.py
```

Проверка на пяти случайных:
```bash
python predict.py 
```
либо на созданном отдельно слоне =)
```bash
python predict.py slon.jpg
```
Так же есть еще два набора весов с другими размерами входных картинок, но там процент был 76,4%+-

## Выводы:
Для лучшего результата было исользовано другая техника прохождения слоев через разбиение на квадраты, чтоб он мог запоминать силуэты животных. Больше всего проблем с узнаванием было у овцы(явно морда не понравилась). В остальном угадывал правильно. Лучше всего угадывал коров. Так же для лучшего обучения в процессе обучения пройденые картинки переворачивались на 180 градусов, чтобы обучалось, если в другую сторону смотрят.
