# Лабораторная работа 1

## Файлы:
dataset.csv — исходные данные с признаками
main.py — ищет число кластеров через метод локтя, делит данные на группы и строит графики
neural_network.py — самописная сетка по шаблону mnist, учится определять кластер по признакам
predict.py — скрипт для выдачи предсказаний на любых данных
requirements.txt — библиотеки
elbow.png — график локтя
clusters.png — картинка с получившимися кластерами
clustered_dataset.csv — готовый размеченный датасет
kmeans_model.pkl — сохраненная модель кластеризации
nn_weights.pkl — сохраненные веса обученной нейросети

## Итог работы
Кластеров ровно 5 штук. На графике локтя перегиб идет именно на пяти, дальше инерция почти не падает. Данные поделились ровно по 20 процентов на каждый кластер, то есть примерно по 10 тысяч точек. Нейросеть обучилась и выдает точность около 90 процентов.

## Как проверять и что запускать
Запуск разбиения по кластерам:
```bash
python main.py
```

Обучение ИИшки:
```bash
python neural_network.py
```

Проверка:
```bash
python predict.py dataset.csv
```
